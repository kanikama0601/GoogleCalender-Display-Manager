# 📡 Google Calendar Display Manager (Forked from Hiroba News Smart Monitor)

リアルタイムで天気・ニュース・Google カレンダーの予定を表示する、軽量なローカル Web ダッシュボードです。

![サンプル画像](./images/0a41516d-73f5-4524-8b00-d12681b06ea2.png)

---

## 🌟 主な機能

- **🕐 時刻表示**: 24時間表記、和暦（令和）、干支、コロン点滅のリアルタイム更新。
- **🌤 天気予報**: 現在の天気、3時間ごとの時間別予報、7日間の週間予報を表示。
- **📅 Google カレンダー連携**: 今日の予定と、月間カレンダー（予定のマーカー付き）を表示。
- **📰 ニュース**: 複数のRSSフィードから最新ニュースをティッカーと一覧で表示。
- **💱 為替レート**: USD/JPY, EUR/JPY, CNY/JPY の最新レートと前週比を表示。
- **🖼 背景画像**: `images/` フォルダ内の画像を 30 秒おきにランダムでスライドショー表示。
- **🎵 音楽/コマンド**: `music/` フォルダの再生や、`commands.json` で定義したコマンドの実行が可能。

## 🚀 セットアップと起動方法

### 1. 依存ライブラリのインストール

Python 3.12 以上を推奨します。Google API を使用するためのライブラリが必要です。

```bash
pip install google-api-python-client google-auth-oauthlib google-auth-httplib2
```
または、`uv` を使用している場合：
```bash
uv sync
```

### 2. Google Calendar API の有効化

カレンダーを表示するには、Google Cloud Console での設定が必要です。

1. [Google Cloud Console](https://console.cloud.google.com/) にアクセス。
2. 新しいプロジェクトを作成、または既存のプロジェクトを選択。
3. 「API とサービス」 > 「ライブラリ」から **"Google Calendar API"** を検索し、有効化。
4. 「API とサービス」 > 「認証情報」から **「認証情報を作成」 > 「OAuth クライアント ID」** を選択。
5. アプリケーションの種類を **「デスクトップ アプリ」** に設定し、作成。
6. 作成されたクライアント ID の **JSON ファイルをダウンロード** し、ファイル名を `credentials.json` に変更してプロジェクトのルートディレクトリ（`run.py` と同じ場所）に保存します。

### 3. 起動

```bash
python run.py
```

初回起動時、ブラウザが開き Google アカウントへのログインと権限の許可が求められます。認証が完了すると `token.json` が生成され、次回以降は自動でログインします。

ブラウザで `http://localhost:8765` を開くとダッシュボードが表示されます。

## 🛠 コマンドライン引数

| 引数 | デフォルト | 説明 |
|------|-----------|------|
| `--city` | `東京都` | 天気エリアの表示名 |
| `--lat` | `35.6895` | 緯度 |
| `--lon` | `139.6917` | 経度 |
| `--port` | `8765` | ポート番号 |
| `--rss URL ...` | なし | RSSフィードを追加（複数可） |
| `--no-default-rss` | なし | デフォルトRSSを無効化 |
| `--compact-clock` | なし | 時計フォントを縮小（小型ディスプレイ向け） |
| `--compact-news` | なし | ニュースをタイトルのみ表示（クリックで詳細展開） |
| `--mouse-hide` | なし | マウスカーソルを非表示にする |
| `--wake-lock` | なし | 画面のスリープを防止する（ブラウザの仕様に依存） |

## 📂 ファイル構成

```
./
├── run.py          # バックエンドサーバー (Python)
├── index.html      # フロントエンド (HTML/JS/CSS)
├── credentials.json # Google API 認証情報 (各自で用意)
├── token.json      # 認証済みトークン (自動生成)
├── commands.json   # カスタムコマンド定義
├── images/         # 背景画像用フォルダ
└── music/          # 音楽ファイル用フォルダ
```

## 📝 動作詳細

- **天気データ**: [Open-Meteo API](https://open-meteo.com/) を使用。30分ごとに更新。
- **ニュース**: 10分ごとに更新。
- **為替レート**: 1時間ごとに更新。
- **カレンダー**: 今日の予定は 5 分ごとに、月間カレンダーは初回および月移動時に更新。
- **キャッシュ**: サーバー側でデータを 5 分間キャッシュし、外部 API への負荷を軽減しています。
